# Personel Yönetim Uygulaması 

- **Mimari:** N-Tier (DataAccess, Business, UI) + Generic Repository Pattern
- **Teknolojiler:** .NET 8, C# WinForms, DevExpress, Entity Framework Core (Code-First), MS SQL Server
- **Kurulum:** `DataAccess/Context/AppDbContext.cs` içerisindeki Connection String düzenlendikten sonra Package Manager Console üzerinden `Update-Database` komutu çalıştırılarak veritabanı oluşturulabilir.
